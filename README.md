# NetSec-Inspector-v1
🛠️ **NetSec Inspector – v1**

🎯 **Features**

* Discover devices on the network
* Scan common ports
* Count open ports
* Provide basic security warnings
* Generate a clear and readable report

📁 **Project Structure**

Create the project folder:

```bash
mkdir netsec-inspector && cd netsec-inspector
```

1️⃣ **Install Requirements**

```bash
pip install python-nmap rich
```

⚠️ **Note:** `nmap` must be installed on the system.
